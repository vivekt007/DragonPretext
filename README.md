# Pretext Playground

An interactive text animation playground featuring a fiery dragon that breathes life into typography. Built with TypeScript, Vite, and Canvas 2D, this project showcases dynamic text physics, particle effects, and responsive design.

## Features
- **Dragon Animation**: Physics-based dragon with wings, spines, fire effects, and enemy interactions
- **Interactive Text**: Click and drag through text to create fire trails and particle explosions  
- **ASCII Animations**: Additional animated scenes in ASCII art style
- **Responsive Design**: Scales beautifully from mobile to desktop
- **Customizable**: Multiple dragon presets and adjustable parameters

Experience where design meets motion and text becomes interface. Perfect for portfolio showcases and creative coding experiments.
